Privacy Policy

Shorts RU / Shorts EN and the 8M1RAG3 website · Last updated: October 24, 2026

Shorts RU / Shorts EN ("the tool") is a private desktop application used only by its owner to upload the owner's own videos to the owner's own YouTube channels "8й Мираж" and "8th Mirage". The tool uses YouTube API Services. "Shorts RU" and "Shorts EN" are the names of the tool's two Google OAuth apps, one per channel. The tool also posts the owner's own videos to the owner's own TikTok accounts (see section 9). This policy also covers this website.

1. YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service: https://www.youtube.com/t/terms. Google's Privacy Policy applies to data processed by Google: http://www.google.com/policies/privacy.

2. What data the tool accesses

When the owner signs in with Google (OAuth 2.0), the tool requests these scopes:

  • youtube.upload — to upload the owner's own videos;
  • youtube.readonly — to read the signed-in channel's name and ID and the public statistics (views, likes, comments) of the owner's own videos.

The tool does not access any other user's data, comments, subscribers, e-mail, contacts or payment information.

3. How the data is used

  • Channel ID and name: to confirm the correct channel before each upload.
  • Video statistics: shown only to the owner to understand which videos perform best.

No data is sold, shared with third parties, or used for advertising.

4. Storage and security

  • The OAuth access/refresh token is stored only on the owner's personal computer in a local file and is never sent anywhere except to Google.
  • Video IDs and statistics are stored locally on the same computer. Statistics are refreshed or deleted within 30 days, in line with the YouTube API Services Developer Policies.
  • No data is stored on any server or cloud owned by the tool.

5. Revoking access and deleting data

The owner can revoke the tool's access at any time at Google Security Settings: https://security.google.com/settings/security/permissions.

To delete all stored data, delete the local "secrets" and "output" folders of the tool. After access is revoked, any stored API data is deleted within 7 days.

6. This website, cookies and tracking

This website does not use cookies, analytics or advertising trackers and does not collect personal data. It only remembers your language choice (RU/EN) in your own browser's local storage. Fonts are loaded from Google Fonts, which may receive your IP address under Google's Privacy Policy. The tool itself is a desktop application and does not use cookies.

7. Children

The tool is not directed to children and is used by one adult owner only.

8. Changes

Changes to this policy will be published on this page with a new "Last updated" date.

9. TikTok

The tool also publishes the owner's own videos to the owner's own two TikTok accounts, @8m1rag3 (Russian) and @8m1rag33 (English), using TikTok Login Kit and the TikTok Content Posting API (Direct Post). TikTok's Terms of Service (https://www.tiktok.com/legal/terms-of-service) and Privacy Policy (https://www.tiktok.com/legal/privacy-policy) apply to data processed by TikTok.

  • Scopes requested: user.info.basic — only the avatar, display name and open_id, used to show which account a video is about to be posted to; video.publish — to publish the owner's own videos.
  • Before each post the owner personally chooses the privacy level, whether comments, Duets and Stitches are allowed, and the commercial content disclosure. Videos are labeled as AI-generated content.
  • Storage: TikTok access and refresh tokens are stored only locally on the owner's personal computer and are sent nowhere except to TikTok. TikTok data is not sold or shared with third parties. No other users use the tool.
  • Revoking access: in the TikTok app go to Settings and privacy → Security → Manage app permissions and remove the app. After revocation the owner deletes the locally stored TikTok tokens.

Политика конфиденциальности

Shorts RU / Shorts EN и сайт 8M1RAG3 · Обновлено: 24 октября 2026 г.

Shorts RU / Shorts EN («инструмент») — частное настольное приложение, которым пользуется только его владелец, чтобы загружать собственные видео на свои YouTube-каналы «8й Мираж» и «8th Mirage». Инструмент использует YouTube API Services. «Shorts RU» и «Shorts EN» — названия двух OAuth-приложений Google этого инструмента, по одному на каждый канал. Инструмент также публикует собственные видео владельца в его собственные аккаунты TikTok (см. раздел 9). Эта политика также распространяется на данный сайт.

1. YouTube API Services

Инструмент использует YouTube API Services. Используя инструмент, вы соглашаетесь с Условиями использования YouTube: https://www.youtube.com/t/terms. К данным, которые обрабатывает Google, применяется Политика конфиденциальности Google: http://www.google.com/policies/privacy.

2. К каким данным есть доступ

Когда владелец входит через Google (OAuth 2.0), инструмент запрашивает разрешения:

  • youtube.upload — загрузка собственных видео владельца;
  • youtube.readonly — чтение названия и ID канала, под которым выполнен вход, и публичной статистики (просмотры, лайки, комментарии) собственных видео владельца.

Инструмент не получает доступа к данным других пользователей, комментариям, подписчикам, электронной почте, контактам или платёжной информации.

3. Как используются данные

  • ID и название канала — чтобы перед каждой загрузкой убедиться, что выбран нужный канал.
  • Статистика видео — показывается только владельцу, чтобы понять, какие видео работают лучше.

Данные не продаются, не передаются третьим лицам и не используются для рекламы.

4. Хранение и безопасность

  • OAuth-токен хранится только на личном компьютере владельца в локальном файле и не отправляется никуда, кроме Google.
  • ID видео и статистика хранятся локально на том же компьютере. Статистика обновляется или удаляется в течение 30 дней в соответствии с правилами YouTube API Services для разработчиков.
  • Никакие данные не хранятся на серверах или в облаке инструмента.

5. Отзыв доступа и удаление данных

Владелец может в любой момент отозвать доступ инструмента в настройках безопасности Google: https://security.google.com/settings/security/permissions.

Чтобы удалить все сохранённые данные, удалите локальные папки инструмента «secrets» и «output». После отзыва доступа все сохранённые данные API удаляются в течение 7 дней.

6. Сайт, cookie и отслеживание

Сайт не использует cookie, аналитику и рекламные трекеры и не собирает персональные данные. Он только запоминает выбранный язык (RU/EN) в локальном хранилище вашего браузера. Шрифты загружаются с Google Fonts, который может получить ваш IP-адрес согласно Политике конфиденциальности Google. Сам инструмент — настольное приложение и cookie не использует.

7. Дети

Инструмент не предназначен для детей, им пользуется только один взрослый владелец.

8. Изменения

Изменения политики публикуются на этой странице с новой датой обновления.

9. TikTok

Инструмент также публикует собственные видео владельца в два его собственных аккаунта TikTok — @8m1rag3 (на русском) и @8m1rag33 (на английском) — с помощью TikTok Login Kit и TikTok Content Posting API (Direct Post). К данным, которые обрабатывает TikTok, применяются Условия использования TikTok (https://www.tiktok.com/legal/terms-of-service) и Политика конфиденциальности TikTok (https://www.tiktok.com/legal/privacy-policy).

  • Запрашиваемые разрешения: user.info.basic — только аватар, отображаемое имя и open_id, чтобы показать, в какой аккаунт будет опубликовано видео; video.publish — публикация собственных видео владельца.
  • Перед каждой публикацией владелец сам выбирает уровень приватности, разрешает или запрещает комментарии, дуэты и стежки и указывает, есть ли коммерческий контент. Видео помечаются как созданные ИИ.
  • Хранение: токены доступа TikTok хранятся только локально на личном компьютере владельца и не отправляются никуда, кроме TikTok. Данные TikTok не продаются и не передаются третьим лицам. Другие пользователи инструментом не пользуются.
  • Отзыв доступа: в приложении TikTok откройте Настройки и конфиденциальность → Безопасность → Управление разрешениями приложений и удалите приложение. После отзыва владелец удаляет локально сохранённые токены TikTok.
